Rally Court keeps a real tennis score: points climb `0 → 15 → 30 → 40`, `40-40`
is deuce, and a player needs a two-point lead to take the game. Six games with a
two-game lead wins the set, or a first-to-seven tiebreak at `6-6`; the match is
best of three. Between points the ball rallies across the net on the `moderate`
spring; the winning point flies to a corner on `slow`, or on `playful` when you
opt in.

## Usage

```tsx
import {
  RallyCourt,
  type RallyCourtLabels,
} from "@/components/matos-ui/rally-court";

const labels: RallyCourtLabels = {
  title: "Match on serve",
  reset: "Reset match",
  you: "You",
  opponent: "Opponent",
  serving: "Serving",
  pointYou: "Point — you",
  pointOpponent: "Point — opponent",
  inRally: "Rally in play",
  deuce: "Deuce",
  advantage: "Advantage, {player}",
  gameWon: "Game, {player}",
  setWon: "Set, {player}",
  matchWon: "Match, {player}",
};

<RallyCourt labels={labels} onMatchEnd={(winner) => console.log(winner)} />;
```

## Props

| Prop            | Type                          | Default | Description                                                             |
| --------------- | ----------------------------- | ------- | --------------------------------------------------------------------- |
| `labels`        | `RallyCourtLabels`            | —       | Every visible string. `advantage` / `gameWon` / `setWon` / `matchWon` take a `{player}` placeholder. |
| `offset`        | `number`                      | `1`     | Elevation steps above the current substrate.                          |
| `playful`       | `boolean`                     | `false` | Send the point-winning ball on the high-bounce `playful` tier.        |
| `defaultServer` | `0 \| 1`                      | `0`     | Which player serves first (`0` is “you”).                             |
| `onPoint`       | `(winner: 0 \| 1) => void`    | —       | Fired on every point.                                                 |
| `onMatchEnd`    | `(winner: 0 \| 1) => void`    | —       | Fired once, when the match is decided.                                |

The scoring is a pure function — `scoreRallyPoint(state, winner)` — and
`formatGameScore` turns raw point counts into `0/15/30/40/Ad`, so the match
logic is testable on its own.

## Court colour

The court ink and surface are local custom properties with token-derived
defaults, so a call site can retint the court without leaving the theme:

```tsx
<RallyCourt
  labels={labels}
  style={{ "--rally-turf": "var(--color-secondary)" } as React.CSSProperties}
/>
```
