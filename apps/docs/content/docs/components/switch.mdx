## Usage

```tsx
import { Switch } from '@/components/matos-ui/switch'
```

```tsx
<Switch
  checked={on}
  onCheckedChange={setOn}
  aria-label="Enable notifications"
/>
```

## Reference

### Props

| Prop              | Type                             | Default                     |
| ----------------- | -------------------------------- | --------------------------- |
| `checked`         | `boolean`                        | — (uncontrolled if omitted) |
| `defaultChecked`  | `boolean`                        | `false`                     |
| `onCheckedChange` | `(checked: boolean) => void`     | —                           |
| `size`            | `"sm" \| "md" \| "lg"`           | `"md"`                      |
| `variant`         | `"filled" \| "outline"`          | `"filled"`                  |
| `shape`           | `"pill" \| "rectangle"`          | `"pill"`                    |
| `content`         | `"default" \| "icon" \| "label"` | `"default"`                 |

`Switch` forwards props to `<button>` (default `type` is `"button"`). Always use **`aria-label`** (or `aria-labelledby`) when there is no visible label.

Also exported: **`switchVariants`** (slots `root` / `thumb`) for extending with `tailwind-variants`.
