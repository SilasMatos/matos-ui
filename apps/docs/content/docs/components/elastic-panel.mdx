## Usage

```tsx
import { ElasticPanel } from '@/components/matos-ui/elastic-panel'
```

```tsx
<ElasticPanel title="What is spring physics?" defaultOpen>
  Height animates with a real spring instead of a fixed duration.
</ElasticPanel>
```

## Reference

### ElasticPanel Props

| Prop          | Type                                  | Default | Description                                    |
| ------------- | ------------------------------------- | ------- | ---------------------------------------------- |
| `title`       | `ReactNode`                           | -       | Trigger label. Required.                       |
| `icon`        | `ReactNode`                           | -       | Optional leading icon.                         |
| `defaultOpen` | `boolean`                             | `false` | Whether the panel starts expanded.             |
| `size`        | `"sm" \| "md" \| "lg" \| "full"`      | `"md"`  | Maximum width preset.                          |
| `stiffness`   | `number`                              | `320`   | Spring stiffness for the height animation.     |
| `damping`     | `number`                              | `22`    | Spring damping for the height animation.       |
