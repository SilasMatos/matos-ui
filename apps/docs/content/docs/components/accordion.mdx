## Usage

```tsx
import {
  Accordion,
  AccordionItem,
  AccordionTrigger,
  AccordionContent,
} from "@/components/ui/accordion"
```

```tsx
<Accordion>
  <AccordionItem value="item-1">
    <AccordionTrigger value="item-1">Título</AccordionTrigger>
    <AccordionContent value="item-1">
      Conteúdo expansível com animação.
    </AccordionContent>
  </AccordionItem>
</Accordion>
```

## Reference

Componentes compound: `Accordion`, `AccordionItem`, `AccordionTrigger`, `AccordionContent`. Cada um aceita props de seu elemento raiz (`div` ou `button`) além de `value` e `children` onde aplicável.
