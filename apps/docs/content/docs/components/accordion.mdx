## Usage

```tsx
import {
  Accordion,
  AccordionItem,
  AccordionTrigger,
  AccordionContent
} from '@/components/matos-ui/accordion'
```

```tsx
<Accordion>
  <AccordionItem value="item-1">
    <AccordionTrigger value="item-1">Title</AccordionTrigger>
    <AccordionContent value="item-1">
      Expandable content with animation.
    </AccordionContent>
  </AccordionItem>
</Accordion>
```

## Reference

Compound components: `Accordion`, `AccordionItem`, `AccordionTrigger`, `AccordionContent`. Each accepts props from its root element (`div` or `button`) plus `value` and `children` where applicable.
