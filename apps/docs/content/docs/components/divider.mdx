## Usage

```tsx
import { Divider } from '@/components/matos-ui/divider'
```

```tsx
<Divider />

<Divider variant="dashed" />

<Divider variant="dotted" color="primary" size="md" />

<div className="flex h-24 items-center gap-4">
  Item
  <Divider orientation="vertical" />
  Item
</div>
```

## Reference

### Props

| Prop          | Type                              | Default        |
| ------------- | --------------------------------- | -------------- |
| `orientation` | `"horizontal" \| "vertical"`      | `"horizontal"` |
| `variant`     | `"solid" \| "dashed" \| "dotted"` | `"solid"`      |
| `color`       | `"default"`                       | `"default"`    |
| `size`        | `"sm" \| "md" \| "lg"`            | `"sm"`         |

`Divider` also accepts all props from `<div>` (horizontal renders a semantic `<hr>`).
