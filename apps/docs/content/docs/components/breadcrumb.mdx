## Usage

```tsx
import {
  Breadcrumb,
  type BreadcrumbItem
} from '@/components/matos-ui/breadcrumb'
```

```tsx
const items: BreadcrumbItem[] = [
  { label: 'Home', href: '/' },
  { label: 'Workspace', href: '/workspace' },
  { label: 'Registry', href: '/workspace/registry' },
  { label: 'Breadcrumb', current: true }
]

;<Breadcrumb items={items} tone="floating" maxVisible={4} />
```

## Reference

### Breadcrumb Props

| Prop          | Type                                           | Default        | Description                                      |
| ------------- | ---------------------------------------------- | -------------- | ------------------------------------------------ |
| `items`       | `BreadcrumbItem[]`                             | -              | Ordered navigation trail.                        |
| `activeIndex` | `number`                                       | Current item or last item | Controlled active crumb.              |
| `maxVisible`  | `number`                                       | `5`            | Collapses the middle of long trails.             |
| `ariaLabel`   | `string`                                       | `"Breadcrumb"` | Accessible label for the navigation landmark.    |
| `onNavigate`  | `(item: BreadcrumbItem, index: number) => void` | `undefined`    | Called when a crumb is selected.                 |
| `size`        | `"sm" \| "md" \| "lg"`                         | `"md"`         | Controls height, radius, and text sizing.        |
| `tone`        | `"default" \| "muted" \| "floating"`           | `"default"`    | Controls the surrounding surface treatment.      |

### BreadcrumbItem

| Field      | Type        | Description                                  |
| ---------- | ----------- | -------------------------------------------- |
| `label`    | `string`    | Visible crumb label.                         |
| `href`     | `string?`   | Renders the crumb as a link when provided.   |
| `icon`     | `ReactNode?` | Optional leading icon.                       |
| `meta`     | `string?`   | Optional small metadata label.               |
| `current`  | `boolean?`  | Marks the item as the current page.          |
| `disabled` | `boolean?`  | Prevents selection and lowers opacity.       |

Also exported: `breadcrumbVariants`, `BreadcrumbProps`, and `BreadcrumbItem`.
