**Matos UI** é uma coleção de componentes estilizados construídos sobre o [shadcn/ui](https://ui.shadcn.com/).

Cada componente pode ser instalado individualmente via CLI do shadcn ou copiado manualmente para o seu projeto.

## Instalação

Instale qualquer componente diretamente no seu projeto:

```bash
npx shadcn@latest add https://matos-ui.com/r/NOME_DO_COMPONENTE.json
```

- Copie ou instale os que precisar no seu projeto
